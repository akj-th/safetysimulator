### 디자인 규칙 (ATELIER-KJ 발표자료 체계)

화면을 새로 만들거나 고칠 때 아래를 따릅니다. 실제 값은 `assets/theme.css` 맨 위 `:root`에 있습니다.

| | |
|---|---|
| 색 | 메인 `#D83D64`(아주 조금만) · 대조 `#2793C9`(보조 강조) · 무채색 `#FFFFFF #CCCCCC #999999 #666666 #333333 #000000` **그 외 색은 쓰지 않음** |
| 글꼴 | Pretendard. 제목 Bold, 본문 Regular |
| 글자 크기 | **`theme.css :root`의 `--fs-*` 토큰으로만** 조절. 화면 CSS에 px을 직접 적지 않습니다 |
| 나누기 | **카드·박스 금지.** 여백과 1px `#CCCCCC` 선으로만 구분 |
| 모서리 | **각지게(0).** 단, 점·토글처럼 원래 동그란 것은 원형 유지 |
| 그림자 | 없음 |
| 강조 | 넓은 면을 메인 컬러로 칠하지 않음. 라벨·번호·핵심 하나에만 |
| 반전 | 강조가 필요한 곳(주요 버튼, 표 머리행)만 검정 바탕 + 흰 글씨 |

**예외 — 문서(`document.html`)의 표 머리행은 옅은 회색입니다** (`#F5F5F5` + 검정 글씨).
문서는 표가 많아 검정 머리행이 줄줄이 이어지면 화면에서도 인쇄물에서도 너무 강합니다.
`.doc th` 안에만 걸어 두었으므로 지도·리포트 화면의 표는 그대로입니다.

**글자 크기 (`--fs-*`)** — 실제 사용자가 공무원이라 작다는 지적을 받아 2026-08 **두 차례** 키웠습니다(본문 13.5 → 15 → 16.5). 5개 화면의 모든 크기가 이 6개 토큰을 가리키므로 **`:root` 숫자만 바꾸면 전 화면에 반영**됩니다.

| 토큰 | 값 | 쓰는 곳 |
|---|---|---|
| `--fs-title` | 29px | 페이지 제목 (h1) |
| `--fs-h2` | 19px | 소제목 (h2), 서식 제목 |
| `--fs-lead` | 17.5px | 페이지 부제, 강조 본문 |
| `--fs-body` | 16.5px | 본문 · 버튼 · 입력창 · **표 내용** |
| `--fs-sm` | 15px | 보조 설명 · 작은 버튼 · 표 머리행 |
| `--fs-cap` | 12px | 캡션 · 각주 · 라벨 · 배지 |

줄간격은 `--lh-body`(1.7) · `--lh-tight`(1.6). **스케일 밖의 예외는 셋뿐**이며 각각 이유를 주석으로 달아 두었습니다 — h1 줄간격 1.4, 리포트 요약 숫자 39/52px, 서식 본문 줄간격 1.95(인쇄용).

**더 키울 때 먼저 터지는 곳** (FHD 기준 남은 여유):

| | 여유 |
|---|---|
| 119 레이어 **7칸 한 줄** | 22px ← 가장 먼저 터짐 |
| 예산표 우선순위 열 | 20px |
| 상단바 (1021px 화면) | 78px |

`--fs-body`를 18px 이상으로 올리면 119 레이어가 한 줄에 안 들어갑니다. 그때는 `index.html`의 `.layer-rows` 칸 수를 7 → 4로 바꿔야 합니다.

- 위험도 색: 안전 `#666666` / 주의 `#000000` / 위험 `#D83D64` — 메인 컬러가 "진짜 위험한 곳" 하나에만 쓰이도록 정한 값입니다.
- **예외 하나**: 119 레이어의 분야별 점 색은 지도에 찍히는 색과 짝을 맞춰야 해서 위 목록 밖의 색을 씁니다 (`index.html`의 `INCIDENT_CATEGORIES`).
- `theme.css`는 예전 변수 이름(`--ink --line --surface --accent --r`)도 새 값으로 연결해 둡니다. 화면별 CSS가 그대로 따라오게 하기 위한 것이니 지우지 마세요.
