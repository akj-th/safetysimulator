## 4. 공식 4대 과업 (시행계획서 기준)

> 아래가 계약상 우리가 납품해야 하는 범위입니다.
> 지금 만드는 **거리뷰 기반 앱은 이 중 과업 2·3·4를 잇는 실행 수단**입니다.

**과업 1 — 7대 재난 통합 데이터 모델 + 백엔드 매칭 알고리즘**
- 분절된 7대 분야 원시데이터를 100×100m 격자 단위로 연계·매핑하는 표준 데이터 구조. (외부 유출 불가한 지자체 내부 보안 환경 전제 → 로컬 데이터 관리 체계)
- 위치별 7대 분야 위해 수준·행정 노력을 정량 연산해 발주팀의 **HEA 4대 진단 유형(Type A·B·C·D)** 으로 자동 분류·매칭.

**과업 2 — 안전사업 인프라 배분 시뮬레이터 (UI/UX)**
- 지자체당 안전사업지구 예산 한도(**개소당 약 10억 원 내외**) 기준, 실무자가 재난 분야별 예산 투자 비중을 직관적으로 조정하는 시뮬레이터.
- 조정 시 격자 취약도와 연계된 표준 시설물의 소요 수량·배치 가능 공간을 실시간 연산해 **지도(오프라인 구동 고려) 상에 시각화**.
- **독립 구동형 프로토타입**: 외부 네트워크 없이 내부망에 단독 설치·구동되는 반응형 웹/모바일 Mock-up + 결과 리포트 출력.

**과업 3 — 폐쇄망 대응 AI 진단 문서 생성 모듈**
- 상용 오픈 API를 쓸 수 없는 **폐쇄망 서버 전제**. 오프라인 독자 구동 경량 LLM(sLLM) + 로컬 추론 엔진.
- 진단 결과 + 시설물 투입 정보 → 안전사업지구 지정 서식(**지정 신청 사유서, 예산 산출 근거, 기대효과**)에 부합하는 표준 텍스트 자동 생성.
- **할루시네이션 방지** + 법정 재난안전 용어 정확 반영 위해 비공개 행정 지침서·단가 표준을 참조하는 데이터 연계(RAG 등). 최종 소스코드 패키징 제출.

**과업 4 — 재난 예방 인프라 표준 설계 가이드라인**
- 7대 재난별 생활권 하드웨어 인프라 설계 지침:
  - 자살·범죄: 옥상 자동개폐장치, 안전 펜스, CPTED 시설 등
  - 교통·생활안전: 바닥형 보행신호등, 핸드레일 등
  - 화재·산재·감염병: 스마트 소화전, 안전 사이니지, 스마트 클린 쉘터 등
- 다중 위험 중첩 공간을 유형화한 **복합 매뉴얼 + 표준 단가 매트릭스** (단일 재난 대책의 매몰 비용 방지).
- 시뮬레이터 결과와 매칭해 즉시 인용 가능한 **시설물별 표준 도면 시안 + 공간 배치 예시도**.

## 5. 우리가 만드는 핵심 파이프라인 (4단계)

1. **입력** — 스트리트뷰 또는 현장 사진 한 장 (지도에서 위치 선택).
2. **진단** — 정해진 체크리스트(7대 분야)로 취약 요소 판독 → HEA Type A~D 매칭. (AI, 추후 연결)
3. **처방** — 진단 결과를 규칙표(과업 4의 시설물·표준단가)에 대입해 시설물 선정. (결정론적 규칙 엔진)
4. **시각화·문서** — 확정된 시설물만 원본 이미지에 렌더링 + 사유서·예산 근거 등 행정 문서(과업 3) 출력.

## 7. 제약·유의사항

- **폐쇄망 vs 온라인 API (최대 쟁점)**: 시행계획서는 "외부 네트워크 연결 없이 내부망 단독 구동"과 "상용 오픈 API 사용 불가"를 명시. 반면 네이버 지도·스트리트뷰는 온라인 호출. → **데모는 온라인으로 진행하되, 최종 납품은 사전 캐싱/오프라인 지도 방식으로 전환 전제.** (이은석 박사 확인 중)
- **스트리트뷰 = 진단의 입력 이미지 그 자체.** 단순 배경이 아니다.
- **지도 시각화도 "오프라인 구동 환경 고려"** 가 시행계획서에 명시됨.
- **소스코드 패키징 제출**이 요건 → 특정 클라우드 전용 방식에 의존하지 말 것.
- **라이선스**: 스트리트뷰 이미지를 변형한 결과물의 2차 저작물 문제에 유의. 캡처해서 AI에 넣고 변형본을 행정 문서에 첨부하는 구조이므로, 지도 사업자 약관 확인 필요. 최종본은 **현장 촬영 사진**으로 가야 할 수도 있음.

### 지도 API 전환 검토 결과 (2026-08, 결론: 네이버 유지)

카카오맵 앱에 캡처 기능이 있어 전환을 검토했으나, **API로는 불가능**한 것을 확인했습니다. 같은 고민을 반복하지 않도록 기록해 둡니다.

| | 로드뷰 렌더링 | 직접 캡처 |
|---|---|---|
| 네이버 | canvas 사용 | ❌ 다른 서버 이미지라 canvas 오염 → 저장 차단 |
| 카카오 | **img 8장을 3D로 조립** | ❌ **canvas 자체가 없음** |

- 카카오맵 **앱**의 캡처는 앱 기능이며 **JavaScript SDK와 무관**합니다.
- 검증 도구: `tools/legacy/kakao-capture-test.html` (카카오 JS 키 필요, 2026-10-27 legacy 로 옮김). 정책이 바뀌면 이걸로 재확인.
- 따라서 **화면공유 방식 캡처를 유지**합니다. 어차피 폐쇄망 최종본에서는 온라인 지도를 못 쓰므로, 이 부분은 데모 편의 문제입니다.
